Binary Triangle Pattern in Java

This program prints a triangle pattern using 0 and 1.

First, we take a variable n which decides the number of rows.

The outer loop runs from 1 to n to print each row.

A variable num is used to store either 0 or 1. The starting value depends on whether the row number is even or odd.

The inner loop prints the value of num and then changes it from 0 to 1 or 1 to 0.

This creates a triangle pattern of alternating 0 and 1.
